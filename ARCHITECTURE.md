# Aqua-Favorit → Rozetka

Управление товарами, ценой, скидкой, наценкой и наличием находится в [таблице New PARSER](https://docs.google.com/spreadsheets/d/1Y3MXEwX6soCr7wP-kEKzu7Cskv3S0cKo1w2ZDaCy85A/edit). Лист `БД` содержит редактируемые данные; лист `Публикация_Rozetka` выдаёт CSV для сборки фида. Артикул хранится текстом, включая ведущие нули.

Локальные циклы обновления цен и остатков передают в `БД` только значения, подтверждённые API сайта при уже выполняемой заливке. Защищённый веб-вызов Apps Script принимает их пакетами и после последнего пакета меняет маркер фида. Повторный экспорт каталога сайта для этих циклов не запускается. Отдельные кнопки таблицы «Загрузить данные с сайта», «Добавить новые товары» и «Обновить скидки» по-прежнему читают API, когда пользователь запускает их вручную.

Рядом с синей кнопкой на листе `БД` четыре редактируемые ячейки `Z1:AC1`: время публикации в часовом поясе Киева. Заполните от двух до четырёх разных значений `ЧЧ:ММ`; пустая ячейка отключает соответствующий запуск. Триггер Apps Script проверяет расписание каждые пять минут и меняет маркер `refresh_token`, когда наступает время. Если обновление после остатков, цен или ручного нажатия уже запрошено за последние 90 минут, ближайший запуск по расписанию считается выполненным без второй сборки. Изменение ячеек не требует перенастройки триггера.

GitHub Actions проверяет опубликованный CSV каждые пять минут. При новом маркере `refresh_token`, ручном запуске задачи либо возрасте последнего фида более 24 часов задача скачивает полный XML сайта, меняет только `price` и `stock_quantity` у совпавших артикулов, проверяет XML и выгружает объекты `aquafavorit_rozetka.xml` и `aquafavorit_rozetka.state.json` в отдельный бакет `aquafavorit-rozetka` аккаунта Info.aquafavorit@gmail.com. Остальные бакеты, объекты и ссылки не затрагиваются.

`БД!W1` показывает дату и время последней подтверждённой публикации XML по Киеву в толстой зелёной рамке. После ошибки рамка становится красной, а в примечании к ячейке доступны этап, причина и ссылка на журнал; текст примечания можно скопировать. Существующий пятиминутный триггер Apps Script читает публичные `aquafavorit_rozetka.state.json` и `aquafavorit_rozetka.health.json`, без запросов к API сайта. При сборке GitHub Actions записывает в `health.json` результат и этап сбоя. Если новый маркер не опубликован за 60 минут или фид старше 26 часов, W1 также сообщает об ошибке. Обычная проверка GitHub без пересборки не перезаписывает этот файл состояния.

Цена: `РРЦ × (1 − Скидка % / 100) × (1 + Наценка % / 100) × курс`. Для UAH курс всегда 1. Курсы остальных валют обновляются из `/api/currency/export/` сайта в лист `Настройки` при загрузке товаров, ручном обновлении фида и по часовому триггеру Apps Script. Если API не возвращает отдельную старую валюту, сохраняется последнее значение таблицы. Например, 1000 грн с наценкой 15% даёт 1150 грн.

В `БД` цены L:M остаются числовыми и показываются с двумя знаками после запятой без разделителя тысяч. Бренд K и поставщик U хранятся обычным текстом без гиперссылок. Для семи вентиляторов Домовент исходная цена сайта сохранена в L, а историческая прибавка около 20% перенесена в V (`Наценка % = 20`); старая цена M уже совпадала со старой таблицей и не менялась.

Независимый планировщик Cloudflare Workers в аккаунте Info.aquafavorit@gmail.com проверяет маркер таблицы каждые пять минут и вызывает существующую задачу GitHub при изменении маркера или возрасте фида более 24 часов. Он также включает задачу обратно, если GitHub отключил её именно из-за 60 дней без активности. Ручное отключение задачи владельцем Worker не отменяет. Worker хранит в секрете ключ GitHub с правом `Actions: write` только для `kezhunya/rozetka`; публичные запросы к Worker возвращают 404. Большой XML собирается в GitHub Actions, Worker его не загружает и не хранит.

Резервный планировщик проверен сквозным запуском GitHub Actions №9. Отчёт `health.json` проверен успешным запуском №12. Временный ключ Cloudflare для развёртывания Worker пользователь решил оставить до 3 ноября 2026 года; локальная копия ключа удалена. Постоянный секрет GitHub, используемый самим Worker, остаётся в Cloudflare.

Нужные секреты репозитория: `CF_R2_ACCOUNT_ID`, `CF_R2_ACCESS_KEY_ID`, `CF_R2_SECRET_ACCESS_KEY`, `CF_R2_BUCKET_NAME`. Ключ R2 должен иметь право записи только в предназначенный бакет. Не храните ключи в файлах репозитория.

Ручной запуск: вкладка Actions → Publish Aqua-Favorit Rozetka XML → Run workflow. Кнопка `Обновить итоговый фид` в таблице меняет маркер и запускает публикацию при следующей проверке, обычно в течение нескольких минут. Итоговый URL: `https://feeds.aqua-favorit.com.ua/aquafavorit_rozetka.xml`.
